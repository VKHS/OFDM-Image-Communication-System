# Historical Lena, BER and OFDM image-results gallery

**Project author: Vahab Khalili**

This page indexes **80 original archived JPG output figures**, now committed to GitHub in their original saved form. They are historical simulation results, **not** newly generated by the Python or MATLAB reference, and some have waveform-power/source-bit-normalization limitations explained in [experiments](EXPERIMENTS.md).

## Interpretation and reproduction

The pictures let you inspect how symbol decision errors appear in the recovered raster; they are not a substitute for calibrated BER/SNR or source-fidelity control. The original archive also has [155 extracted report figures in ZIP bundles](../archive), [49 design/reference figure assets](../archive/new_design_and_recomputed_figures.zip), and [47 archived model files](../archive/archived_simulink_models.zip). The [image-to-image MATLAB sweep](../matlab/README.md) reproduces **new numerical reference results** with explicit signal power calibration, instead of claiming to rerun archived Simulink screenshots.

For a complete view of the calculations and limitations, start with the [master technical report](MASTER_TECHNICAL_REPORT.md) and [scenario catalog](SCENARIOS.md).
